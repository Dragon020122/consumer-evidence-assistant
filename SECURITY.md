# Security policy

## Scope

This repository is a local MVP and portfolio demonstration, not a production service. It only contains fictional demonstration data. Do not submit consumer-dispute materials, personal information, credentials, payment records, or identity documents through public GitHub Issues, Discussions, or pull requests.

## Reporting a vulnerability

Please use GitHub's private security-reporting channel to contact the maintainer. If that channel is not enabled, open a minimal public issue that contains no exploit details or personal data and asks the maintainer for a private contact route.

Do not publish working exploit steps, tokens, or copied user materials in a public thread.

## Current limitations

The repository intentionally uses local SQLite, private local storage, mock extraction, and development-only authentication. It has not been reviewed or approved for production use. Any production deployment requires a separate security, privacy, legal, authentication, storage, monitoring, backup, and incident-response review.
