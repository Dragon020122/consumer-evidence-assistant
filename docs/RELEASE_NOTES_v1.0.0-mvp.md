# v1.0.0-mvp 发布说明（仅本地准备）

## 定位

AI消费纠纷证据整理助手是一个本地、中文、求职作品集 MVP。它用虚构材料演示“证据 → 确认 → 时间线 → 矩阵 → 草稿/导出”的人机协同整理流程，不是法律服务或生产系统。

## 核心能力

- 8 步普通用户工作流与 8 份虚构演示材料、18 项提取结果。
- USER、REVIEWER、ADMIN 三角色与服务端 RBAC、所有权、复核分配。
- 提取确认、时间线、事实—证据矩阵、缺口规则、草稿和 6 PDF/3 ZIP 导出。
- 私有文件、审计摘要、级联删除、DTO 边界与环境化 CSP。

## AI 与测试

演示默认使用 Mock Provider；输出经过 Zod 校验并需用户确认。当前通过 lint、typecheck、21 文件/64 测试、7 文件/23 集成测试、3 文件/6 E2E 测试与生产构建。

## 不包含什么

不包含真实 OCR/LLM、支付、政府投诉提交、律师服务、结果预测、自动赔偿计算、真实消费者数据或生产部署。

## 本地运行

见根目录 README 的“本地运行”和 [演示指南](DEMO_GUIDE.md)。不要提交 `.env.local`、数据库、私有文件或本地导出。
