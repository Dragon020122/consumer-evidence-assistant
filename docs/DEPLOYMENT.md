# 部署说明

本仓库当前只支持本地和隔离测试环境，不应直接部署生产。

## 本地

复制 `.env.example` 到 `.env.local`，替换所有 `change-me` 与签名密钥，执行迁移、种子和 `npm run dev`。数据库、上传和生成目录均被 Git 忽略。

## 测试环境

使用独立磁盘和独立虚构数据；关闭公网索引；限制访问来源；定期运行 `npm run cleanup`。如使用容器，必须把三个数据目录映射到受控私有卷。

## 正式上线前必须人工完成

PostgreSQL/私有对象存储迁移、生产认证、密钥管理、HTTPS/反向代理、安全响应头、CSRF 策略复核、备份恢复、监控告警、中文字体授权、供应商评估、隐私/合规与专业法律边界审查、压力/渗透/灾备测试。生产必须设置 `DEV_AUTH_ENABLED=false`。
