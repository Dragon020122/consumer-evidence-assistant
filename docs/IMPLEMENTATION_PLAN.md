# 实施计划

1. 工程、文档、数据库迁移、安全日志、UI 壳层、测试与 CI。
2. 开发认证、适用性预筛、案件创建、所有权校验、证据上传与私有存储。
3. OCR/模型适配、Mock 提取、结构校验、用户确认、时间线。
4. 事实证据矩阵、缺口规则、草稿、中文 PDF 和 ZIP。
5. 人工复核队列、管理员分配、审计、模拟套餐与订单。
6. 级联删除、到期清理、移动端页面状态和完整导航。
7. 单元、集成、工作流 E2E 与安全审查，修复中高风险问题。
8. 全量质量门槛、文档收口和最终报告。

每批次执行：实现 → 测试 → lint/typecheck/test/build → 修复 → 复验 → 更新 `PROGRESS.md` → Git commit。
