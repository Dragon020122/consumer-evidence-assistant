# 测试计划

## 自动化层级

- 单元：金额/日期解析、Schema、日志脱敏、权限、时间线、证据关联、缺口和删除规则。
- 集成：数据库迁移、创建案件、上传、提取确认、生成、复核、导出、删除。
- 工作流 E2E：虚构“星云健身中心”年卡 2999 元案例，从预筛到导出和删除。
- 构建门槛：ESLint、TypeScript、Vitest、Next production build。

## 安全用例

覆盖跨用户 IDOR、未分配复核员、管理员边界、路径穿越、伪装 MIME、重复文件、超限、XSS 数据、SQL 注入输入、CSRF 来源、提示注入、敏感日志、删除残留和公开链接。

## 测试数据规则

只使用虚构商家、人员、号码与文本；不复制真实聊天、证件或付款材料。不得通过删除有效用例或弱化核心断言解决失败。
