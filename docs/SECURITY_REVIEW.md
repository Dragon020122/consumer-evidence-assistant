# 安全审查报告

审查日期：2026-07-11。范围为本地脱敏测试版，不代表生产渗透测试或法律合规意见。

## 已验证控制

- 资源授权：普通用户只能访问自己的案件/证据/生成文件；复核员只能访问分配案件；管理员操作单独授权并审计。
- 文件：随机私有存储键、目录边界校验、允许列表、扩展名/MIME/魔数、大小/数量、二进制 TXT、哈希查重、授权下载、总导出量限制。
- 输入与输出：Zod 结构校验、SQLite 参数化查询、React 默认转义、资源 ID 长度限制、同源写请求、SameSite/HttpOnly 会话。
- 模型边界：证据文本是非可信数据，提示注入测试不会改变提取规则；模型前可配置敏感信息脱敏；失败结果进入人工处理。
- 删除：级联删除数据库记录，逐一删除原/生成文件，失败可重试，只保留脱敏审计摘要。
- 平台：CSP、frame-ancestors/X-Frame-Options、nosniff、no-referrer、权限策略和 COOP。
- 供应链：仓库密钥扫描通过；PostCSS 升级覆盖后 `npm audit --omit=dev --audit-level=moderate` 为 0 漏洞。

## 审查中发现并修复

1. 合法上传扩展名与严格随机路径片段冲突：存储键改为纯随机 ID，扩展名只保留在元数据。
2. 时间线曾把非付款材料中的单独日期生成付款事件：查询加入证据分类，只允许付款/订单材料生成付款事件。
3. 测试临时目录并行清理互相影响：测试文件串行隔离，消除删除/导出竞态误报。
4. PostCSS CSS 序列化 XSS 中风险：覆盖到 8.5.16，复审 0 漏洞。
5. 大材料包可能造成内存压力：加入可配置的 100MB 原始材料总量限制。
