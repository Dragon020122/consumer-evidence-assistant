# 产品需求文档

## 定位

帮助消费者整理消费纠纷材料、建立时间线、制作证据目录、发现材料缺口，并生成可核对的材料草稿。测试版用于演示和脱敏小规模测试，不提供法律意见，不代替用户、监管部门或专业人员作判断。

## 第一版范围

支持健身房、美容美发/美容院、成人或儿童培训，以及摄影、宠物、家政等一般预付服务退费材料整理。

暂不支持医疗、投资理财、借贷、劳动、婚姻家庭、严重人身伤害、刑事、房屋买卖纠纷，也不支持自动诉讼、自动举报、律师撮合或正式支付。预筛命中排除项时停止自动生成并显示安全边界提示。

## 用户与角色

- 普通用户：仅管理自己的案件和文件。
- 人工复核员：仅查看分配给自己的案件，可检查和提出修改建议，不能改原始文件或用户诉求。
- 管理员：管理测试案例、分配复核员、查看运行状态和脱敏审计记录。

## 核心闭环

首页 → 适用性预筛 → 创建案件 → 填写信息 → 上传证据 → Mock/可替换服务提取 → 用户逐项确认 → 时间线确认 → 事实证据矩阵 → 材料缺口 → 草稿预览 → 自动交付或人工复核 → PDF/ZIP 下载 → 删除案件。

## 验收原则

- 关键事实未经用户确认不得进入最终材料。
- 有证据的时间线项至少关联一份原始证据；否则必须标为用户陈述。
- 所有输出标记“草稿，请核对”，不包含成功承诺、违法认定、确定赔偿、威胁或虚假事实。
- 移动端完成核心闭环，所有长任务有进度、保存、失败和重试反馈。
