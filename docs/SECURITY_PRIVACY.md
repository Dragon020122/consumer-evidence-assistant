# 安全与隐私说明

## 已实现边界

- 案件资源在服务端按用户所有权或复核分配关系校验。
- 管理员、复核员和普通用户使用独立的 RBAC 路径；前端导航不是授权替代。
- 上传执行扩展名、MIME、魔数、大小、数量、哈希去重和路径规范化检查。
- 原始文件位于私有目录，下载接口再次授权；客户端 DTO 不暴露 `storageKey`、哈希或 Buffer。
- 日志递归脱敏敏感字段，审计仅保留操作元数据。
- 删除案件会清理数据库子记录、私有原文件和生成文件，并留下不可反推内容的摘要。
- 开发演示仅在非生产且显式开启时有效；生产 CSP 不包含 `unsafe-eval`。

## 数据原则

公开仓库与测试仅使用虚构材料；不把用户材料用于训练模型；不把真实材料放到 GitHub、日志或截图中。

## 生产前必须重新审查

本项目不宣称绝对安全或完全合规。生产化需要企业认证、密钥管理、生产数据库、私有对象存储、备份恢复、限流与监控、供应商数据处理评估、渗透测试、隐私与法律审查、事件响应与删除证明流程。
