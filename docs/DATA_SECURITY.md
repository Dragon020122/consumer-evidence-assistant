# 数据安全与隐私

## 最小化与用途

只收集整理案件所需字段。测试与演示仅使用虚构数据。原始材料不得用于训练模型，默认不发送给第三方。

## 控制措施

- 服务端认证、角色校验、案件所有权/复核分配校验。
- 上传采用扩展名、MIME、魔数、大小、数量、哈希重复和路径规范化检查。
- 本地存储目录不在 `public` 下，文件名使用随机 ID，下载必须再次授权。
- OCR/模型结果经 Zod 校验，不确定值为 `null`；证据文本以不可信数据封装。
- 模型调用前可配置脱敏身份证、银行卡、完整手机号和详细地址；Mock 模式全程本地运行。
- 日志递归脱敏身份证、银行卡、手机号、令牌、密码和敏感字段，禁止记录原文。
- 数据库参数化查询；界面默认转义输出；状态变更使用同站 Cookie 和来源校验。
- 审计仅记录行为、资源 ID、角色、时间和结果，不记录证据正文。
- 全站设置 CSP、禁止嵌入、MIME 嗅探、来源/referrer 和摄像头/麦克风/定位限制；导出原始材料总量默认限制为 100MB。

## 删除与保留

案件保存 `expires_at`。用户删除或清理任务执行事务性数据库删除，并清理上传/生成目录；随后写入不可反推内容的删除摘要。测试版默认保留 30 天，可由环境变量调整。
