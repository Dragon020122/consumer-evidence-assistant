# 已知限制

- 这是 `v1.0.0-mvp` 本地作品集，不适用于未经审查的生产环境。
- 仅覆盖预付式消费服务材料整理；不处理医疗、投资、劳动、刑事等排除领域。
- 当前使用 Node SQLite 与私有本地文件存储；生产需要替换为受审查的数据库和对象存储。
- 演示模式使用 Mock 提取：TXT 仅解析明确模式，图片/PDF 不猜测内容而进入人工确认。
- 不接入真实 OCR、LLM、支付、短信、邮件、政府平台或真实消费者数据。
- 没有正式 MFA、账号恢复、集中会话吊销、分布式限流、备份恢复或监控体系。
- 草稿不是法律意见，不包含违法认定、成功承诺或自动投诉提交。

这些限制是刻意的产品与安全边界，不应用营销文案掩盖。
